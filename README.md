
# Student Management System

A web-based Student Management System built using Python Flask, HTML, CSS, and SQLite.

## Features

- Add new students
- View student records
- Edit student information
- Delete student records
- Store student information in SQLite database

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite

## Installation

1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Install the required package:

   pip install -r requirements.txt

5. Run the application:

   python app.py

6. Open this address in your browser:

   http://127.0.0.1:5000

## Database

The SQLite database is initialized automatically when the application starts.
